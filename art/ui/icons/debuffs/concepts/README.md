# Concept Candidates

These SVGs deliberately vary the symbol meaning rather than only the drawing style. Every file is 128 x 128, transparent, and uses only `#ff0000`.

| Status | Existing root icon | Additional concepts |
|---|---|---|
| Bleeding | cracked blood drop | open wound with drip; soaked bandage; blood trail |
| Fracture | snapped limb (formal) | split joint; cracked bone |
| Broken leg | classic side wheelchair (formal) | compact symbol, large wheel with footrest, backrest structure |
| Hungry | slim tapered knife (formal) | slim chef, slim tall, slim rounded knife |
| Exhausted | slumped runner (formal) | empty sprint meter, low gauge, breathless figure |
| Rain exposure | rain figure (formal) | rain cloud, soaked hood, broken umbrella |

Choose by the filename concept, not by `a`, `b`, or `c` in the older visual-style experiment.

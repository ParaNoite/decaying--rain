# Debuff Icons

All assets are 128 x 128 SVG icons with a transparent background and only `#ff0000`.

The root files are the selected no-frame UI icons. Other alternatives are in `candidates/` and `concepts/`:

- `a-*`: direct outline symbols: cracked blood drop, broken bone, damaged legs, empty bowl.
- `b-*`: bolder survival symbols: cut bandage, struck bone, crossed damaged legs, hollow stomach.
- `c-*`: compact HUD symbols: blood drops, fractured bone, damaged legs with impact mark, empty plate.

Selected root icons:

- `bleeding.svg`: cracked blood drop
- `fracture.svg`: snapped limb
- `broken-leg.svg`: classic side wheelchair
- `hungry.svg`: empty plate, fork, and slim tapered knife
- `exhausted.svg`: slumped runner
- `rain-exposure.svg`: rain-exposed figure

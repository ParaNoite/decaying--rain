# Debuff Icons

All assets are 128 x 128 SVG icons with a transparent background and only `#ff0000`.

The root files use the `a` no-frame line-icon set. Other alternatives are in `candidates/`:

- `a-*`: direct outline symbols: cracked blood drop, broken bone, damaged legs, empty bowl.
- `b-*`: bolder survival symbols: cut bandage, struck bone, crossed damaged legs, hollow stomach.
- `c-*`: compact HUD symbols: blood drops, fractured bone, damaged legs with impact mark, empty plate.

Each set contains `bleeding`, `fracture`, `broken-leg`, and `hungry`.

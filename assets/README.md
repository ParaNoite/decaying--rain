# Assets

Imported runtime assets live here.

- `audio/music/`: music loops and stems.
- `audio/sfx/`: one-shot and looped sound effects.
- `fonts/`: UI and debug fonts.
- `materials/`: reusable material resources.
- `models/`: 3D meshes and source-ready model exports.
- `shaders/`: Godot shader files.
- `textures/`: imported image textures.
- `ui/`: HUD and screen assets.

Keep source-only art files in `art/` unless they are imported by Godot.

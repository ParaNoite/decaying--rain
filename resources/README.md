# Resources

Data-driven gameplay content lives here as `.tres` files backed by Resource classes under `scripts/resources/`.

- `gameplay/enemies/`: enemy definitions.
- `gameplay/events/`: random event definitions.
- `gameplay/professions/`: profession definitions.
- `gameplay/waves/`: wave definitions.
- `gameplay/weapons/`: weapon definitions.
- `loot/`: loot table definitions.
- `meta/`: unlock and profile data definitions.
- `themes/`: Godot theme resources.

# MVP 音频素材清单

本文档是正式 WAV 素材的交付清单。所有文件最终放入 `assets/audio/sfx/`，Cue 登记在 `resources/audio/mvp_audio_catalog.tres`。文件名使用小写点号命名，实际文件可使用同名下划线文件名，但 Cue ID 不变。

## 交付约定

- 短促、需要精确同步的音效：16-bit WAV，44.1 kHz 或 48 kHz。
- 3D 定位音效：单声道 WAV；全局 UI 音效可使用立体声。
- 单次音效首尾预留 2-5 ms 淡入/淡出，避免点击声。
- 每个事件优先提供 3-5 个变体；脚步、命中、雨滴等高频事件至少 5 个变体。
- 文件名建议：`<cue_id>.wav`，变体使用 `_01`、`_02` 后缀。
- “当前接入”表示已经有运行时事件；“待独立接入”表示应制作并登记独立 Cue，当前代码可能仍使用兼容映射。

## 音乐文件（独立于短音效）

音乐使用 OGG 或长 WAV；以下 Cue 需要正式版本替换当前占位文件：

- `music.daylight`：白昼探索
- `music.preparation`：准备阶段
- `music.rain`：降雨/战斗阶段
- `music.settlement`：结算阶段
- `music.complete`：完成结局
- `music.failed`：失败结局

## 当前优先级

1. 第一优先：脚步、普通/重攻击、枪械射击、命中、受击、死亡、敌人攻击/死亡、拾取、Watch、雨声。
2. 第二优先：装填三段、招架起手/成功、推搡起手/命中、跳跃/落地、滑铲、容器交互。
3. 第三优先：地面材质分层、敌人受击/警觉、雷声、风声、基地机械、波次和跑局提示。

# MVP Milestones

## M0: Runnable Graybox

Goal: player can move, attack, take damage, and kill a basic enemy.

- Graybox test level.
- Player movement, sprint, slide.
- Basic health and damage.
- One chasing melee enemy.
- Basic melee, block, and shove hooks.

## M1: Day / Rain Loop

Goal: daylight, preparation, rain, settlement, and next-wave flow can run end to end.

- Fixed base graybox.
- External scavenging graybox.
- Phase timer and transitions.
- Resource point interaction.
- 5-wave run endpoint.

## M2: Combat And Base Pressure

Goal: defense pressure is playable.

- Melee weapon parameters.
- Blocking and stamina costs.
- Firearm interface.
- Repairable doors / barriers.
- Beacon core damage and failure.

## M3: Content Complete

Goal: full MVP roster is connected.

- 4 enemy definitions.
- 5 wave definitions.
- Opening Perk / profession prototype: deserter.
- Perk active skill, shared baseline stats, and explicit advantage/disadvantage rules.
- Hunger.
- Status interface.
- 2 random events.
- Hold-to-open player watch UI with wave countdown, map, and detail panel.

## M4: Demo Ready

Goal: readable demo build.

- HUD, watch UI, and feedback.
- Basic audio hooks.
- Simple visual replacements.
- Win/fail settlement and restart flow.

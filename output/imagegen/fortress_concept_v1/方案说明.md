# 山脊指挥堡垒：概念预审

本轮只生成效果图和建筑布局图，不修改 Godot 场景。

现有地图东北侧原名为“高危堡垒预留”，占位 54 × 44 米，基础标高约 +8 米。定位可以进一步确定为敌方大本营；原文件并没有定义敌方组织成员、剧情或驻军数量，本方案不额外确定这些内容。

## 设计目标

从南侧基地出发即可辨认山顶轮廓，接近时依次经历山脚入口、半山院落、山顶指挥区。压迫感来自山体、挡土墙和建筑的叠加，而不是所有室内空间一律放大。

| 部分 | 概念目标 |
|---|---|
| 山体包络 | 约 140 × 120 米，向现地图东北外扩 |
| 营区范围 | 约 110 × 85 米，约为原占位面积的 3.9 倍 |
| 山脚关卡 | 相对谷地道路 +8 米 |
| 半山营房、工坊、院落 | 相对谷地道路 +21 米 |
| 山顶指挥区 | 相对谷地道路 +35 米 |
| 指挥主楼 | 约 42 × 18 米、四层，东端设观察塔 |
| 主路 | 西侧折返上山，概念净宽 6 米 |
| 次要路径 | 东侧检修梯，连接不同台地 |

这些标高以谷地道路为参照，不是当前 Godot 世界坐标。观察塔的最终高度、山体边界、实际爬升距离都应在后续尺度样机确定。扩大范围需要改动地图东北边界，不能直接将大营区塞回原地块。

## 本轮验收方法

1. 看效果图：能否第一眼识别大本营，山坡本身是否足够有分量，是否保持阴雨工业林地风格。
2. 看建筑图：三层台地是否有区别，主路和检修梯是否清楚，中层院落是否有停留和探索空间。
3. 确认是否接受营区面积约增至四倍，以及地图向东北外扩的方向。
4. 不以生成图精确判断坡度、净空和距离；图中投影、标签和小图可能有偏差。后续搭建必须重新验证道路连接、爬升耗时、出生点视线和遮挡。
